# Local do projeto

## Site (codigo + public)

`D:\Sem Talento Studio\Projeto Website`

Para rodar: `iniciar.bat` ou `npm run dev`

## Arquivo-fonte (Assets)

Destino sugerido apos mover:

`D:\Sem Talento Studio\Assets`

Configure `.assets-root` na raiz do site (veja `.assets-root.example` e `docs/ASSETS.md`).

O site **nao** precisa de Assets em runtime — apenas `public/` e o codigo.
